# 🎡 วงล้อสุ่มชื่อนักเรียน (Classroom Wheel of Names)

เว็บแอปพลิเคชันสุ่มชื่อนักเรียนสำหรับคุณครูและห้องเรียน ลื่นไหล ทันสมัย **ไม่มีโฆษณา 100%** พร้อมใช้งานบนโปรเจกเตอร์ สมาร์ททีวี คอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน

---

## ✨ ฟีเจอร์เด่น (Features)

- 🎯 **วงล้อหมุนสมูท & ฟิสิกส์สมจริง**: แสดงชื่อภาษาไทยและอังกฤษได้อย่างคมชัด สวยงาม ด้วย Canvas Graphics
- 🔊 **ระบบเสียงในตัว (Zero Dependency)**: เสียงติ๊กเข็ม (Tick) และเสียงฉลอง (Fanfare) ด้วย Web Audio API โหลดไวและไม่หลุดแน่นอน
- 🎊 **เอฟเฟกต์พลุเฉลิมฉลอง (Confetti Animation)**: สร้างบรรยากาศสนุกสนานเมื่อได้ผู้โชคดี
- 🏫 **ระบบจัดการห้องเรียน (Classroom Management)**:
  - เพิ่ม/ลบ ห้องเรียนได้ไม่จำกัด (เช่น ม.1/1, ม.1/2, ม.2/3)
  - บันทึกข้อมูลลงในเบราว์เซอร์อัตโนมัติ (LocalStorage) ข้อมูลไม่หายเมื่อปิดหน้าเว็บ
- ❌ **ฟังก์ชันจัดการชื่อผู้ชนะ**: เลือกว่าจะ "ลบชื่อผู้ชนะออกจากวงล้อ" หรือ "คงชื่อไว้"
- 🔀 **สลับตำแหน่งชื่อ (Shuffle)**: สุ่มจัดเรียงลำดับสีและช่องของชื่อนักเรียนใหม่ได้ใน 1 คลิก
- 📜 **ประวัติการสุ่ม (History Log)**: ดูย้อนหลังได้ว่าสุ่มใครไปแล้วบ้าง พร้อมเวลาที่สุ่ม
- 🖥️ **โหมดเต็มจอ (Fullscreen Mode)**: เหมาะสำหรับการฉายขึ้นโปรเจกเตอร์หรือทีวีในห้องเรียน
- ⌨️ **ปุ่มลัดคีย์บอร์ด**: กดปุ่ม `Spacebar` หรือ `Enter` เพื่อหมุนวงล้อได้ทันที, กด `Esc` เพื่อปิดหน้าต่างผลลัพธ์
- 🌙 **ธีมมืดและสว่าง (Dark / Light Mode)**: ถนอมสายตา และปรับเปลี่ยนได้ตามความชอบ

---

## 🚀 วิธีการนำขึ้น Vercel (Step-by-Step Deployment)

1. ไปที่เว็บไซต์ [vercel.com](https://vercel.com) แล้วเข้าสู่ระบบด้วยบัญชี GitHub ของคุณ
2. คลิกปุ่ม **"Add New..."** > **"Project"**
3. เลือกคลัง (Repository) ชื่อ **`Wheelofname`**
4. ในส่วน **Framework Preset** ให้ปล่อยเป็น **Other** (หรือ Default)
5. คลิกปุ่ม **"Deploy"**
6. ภายในเวลาไม่ถึง 1 นาที เว็บไซต์ของคุณจะพร้อมใช้งานและได้ URL เช่น `https://wheelofname-xxx.vercel.app` ฟรีตลอดชีพ!

---

## 🛠️ โครงสร้างไฟล์ในโปรเจกต์

- `index.html` : โครงสร้างหน้าเว็บหลักและ Modal ต่างๆ
- `style.css` : ระบบ Design System, Responsive Layout และ Dark/Light Mode
- `app.js` : ลอจิกการหมุนวงล้อ, ระบบเสียงสังเคราะห์, Confetti และ LocalStorage
- `vercel.json` : การตั้งค่าความปลอดภัยและ Performance สำหรับ Vercel
- `.gitignore` : จัดการไฟล์ระบบ
